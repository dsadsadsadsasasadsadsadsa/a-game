# Web version — Guess the Number

This is a static web version of the "Guess the Number" game.

Usage
1. Open `web/index.html` in any modern web browser (no server required).
2. Adjust the minimum and maximum values, then click "Start Game".
3. Enter guesses and press the "Guess" button or Enter.

Notes
- The secret number is generated in the browser using JavaScript.
- For debugging the secret number is logged to the console; remove the console.log line if you don't want that.

Enjoy!
